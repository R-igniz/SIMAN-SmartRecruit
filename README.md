## 📖 Descripción

**SIMAN SmartRecruit** es una plataforma web moderna diseñada para optimizar el proceso de requisición y gestión de personal en el Departamento de Recursos Humanos de SIMAN. El sistema ofrece una experiencia intuitiva y profesional, inspirada en las mejores prácticas de diseño corporativo como **Microsoft Fluent Design**, **SAP Fiori**, y **Material Design 3**.

### 🎯 Objetivo

Agilizar y centralizar la gestión de contrataciones, proporcionando herramientas inteligentes para:
- Creación y seguimiento de requisiciones
- Asignación automática a reclutadoras
- Dashboard ejecutivo con KPIs en tiempo real
- Asistente de IA para apoyo en decisiones estratégicas

---

## ✨ Características

### 🖥️ Dashboard Principal
- **KPIs en tiempo real**: Vacantes abiertas, cerradas, contrataciones del mes
- **Gráficas interactivas**: Vacantes por comercial y reclutadora
- **Actividad reciente**: Seguimiento de últimas requisiciones
- **Alertas inteligentes**: Notificaciones de solicitudes urgentes

### 📝 Gestión de Requisiciones
- **Wizard de 4 pasos**: Información General → Puesto → Adjuntos → Resumen
- **Guardado automático**: Borradores y envío final
- **Asignación automática**: A reclutadora correspondiente

### 👩‍💼 Panel de Reclutadora
- **Lista de requisiciones asignadas**
- **Filtros avanzados**: Centro, estado, prioridad, fecha
- **Tarjetas de resumen**: Información clave de cada requisición
- **Administración**: Timeline de estados y comentarios

### 📊 Dashboard Ejecutivo
- **Métricas estratégicas**: Tiempo promedio, tasa de éxito
- **Top reclutadoras**: Ranking de desempeño
- **Embudo de reclutamiento**: Visualización de conversión
- **Análisis por tienda**: Distribución de vacantes

### 🤖 SmartRecruit AI
- **Chat inteligente**: Responde preguntas en lenguaje natural
- **Sugerencias predictivas**: Recomendaciones automáticas
- **Análisis de cuellos de botella**: Identificación de problemas

### 📈 Reportes
- **Tabla de datos**: Lista completa de requisiciones
- **Filtros avanzados**: Múltiples criterios de búsqueda
- **Exportación**: PDF y Excel

### ⚙️ Configuración
- **Gestión de usuarios y roles**
- **Administración de catálogos**: Comerciales, tiendas, departamentos
- **Plantillas y correos**: Personalización de comunicación
